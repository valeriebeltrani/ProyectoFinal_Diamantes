# ProyectoFinal_Diamantes
Proyecto Final - Analítica de los Negocios. Análisis de regresión lineal sobre la base "diamonds.csv" para responder: ¿cuánto aumenta el precio de un diamante por cada quilate adicional y cuánto valor aportan el color, la claridad y el corte? Los resultados buscan orientar decisiones de inventario y fijación de precios en una joyería.
